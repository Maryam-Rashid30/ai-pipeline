# Requirements — Simple Todo App

## What to build
A single-page web application that lets a user manage a todo list.

## Features
- Add a new todo item via a text input and a button
- Mark a todo as complete with a strikethrough
- Delete a todo item
- Show a count of remaining incomplete items
- Persist todos in localStorage

## Tech
- Plain HTML, CSS, JavaScript
- Single file output (index.html)
- Must work in Chrome

## Acceptance criteria
- All features work correctly
- No console errors
- Page works on mobile (375px wide)
